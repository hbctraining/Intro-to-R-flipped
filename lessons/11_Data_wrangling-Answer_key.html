Reading in and inspecting data

  1. Using the animals.csv, read the .csv file into your environment and assign it to a variable called animals. Be sure to check that your row names are the different animals.
# Read in animals.csv
animals <- read.csv("data/animals.csv")

# Print animals
animals

Cheetah   120.0   Tan
Tortoise    0.1 Green
Hare       48.0  Grey
Lion       80.0   Tan
PolarBear  30.0 White
  1. Check to make sure that animals is a dataframe.
# Check the class of animals
class(animals)

# Number of rows in animals
nrow(animals)

ncol(animals)

Data wrangling

  1. Extract the speed value of 40 km/h from the animals dataframe.
# Various methods to extract the speed value of 40 km/h
animals[1,1]
[1] 40
animals[which(animals$speed == 40), 1]
[1] 40
animals[which(animals$speed == 40), "speed"]
[1] 40
animals$speed[which(animals$speed == 40)]
[1] 40
  1. Return the rows with animals that are the color Tan.
# Two way to return the rows with the animal color as Tan
animals[c(2,5),]
        speed color
Cheetah   120   Tan
Lion       80   Tan
animals[which(animals$color == "Tan"),]
        speed color
Cheetah   120   Tan
Lion       80   Tan
  1. Return the rows with animals that have speed greater than 50 km/h and output only the color column. Keep the output as a data frame.
# Return the color for animals faster than 50 km/h
animals[which(animals$speed > 50), "color", drop =F]
        color
Cheetah   Tan
Lion      Tan
  1. Change the color of “Grey” to “Gray”.
# Two ways to change Grey to Gray
animals$color[which(animals$color == "Grey")] <- "Gray"
animals[which(animals$color == "Grey"), "color"] <- "Gray"
  1. Create a list called animals_list in which the first element contains the speed column of the animals dataframe and the second element contains the color column of the animals dataframe.
# Create a list with the speed and color vectors
animals_list <- list(animals$speed, animals$color)
  1. Give each element of your list the appropriate name (i.e speed and color).
# Name the vectors in the list
names(animals_list) <- colnames(animals)

The %in% operator, reordering and matching

In your environment you should have a dataframe called proj_summary which contains quality metric information for an RNA-seq dataset. We have obtained batch information for the control samples in this dataset. Copy and paste the code below to create a dataframe of control samples with the associated batch information:

# Read in proj_summary if needed
proj_summary <- read.table(file = "data/project-summary.txt", header = TRUE, row.names = 1)

# Create ctrl_samples dataframe
ctrl_samples <- data.frame(row.names = c("sample3", "sample10", "sample8", "sample4", "sample15"), 
                            date = c("01/13/2018", "03/15/2018", "01/13/2018", "09/20/2018","03/15/2018"))
  1. How many of the ctrl_samples are also in the proj_summary dataframe? Use the %in% operator to compare sample names.
# Number of shared samples between ctrl_samples and proj_summary
length(which(rownames(ctrl_samples) %in% rownames(proj_summary)))
[1] 3
  1. Keep only the rows in proj_summary which correspond to those in ctrl_samples. Do this with the %in% operator. Save it to a variable called proj_summary_ctrl.
# Subset proj_summary by the samples within ctrl_samples
proj_summary_ctrl <- proj_summary[which(rownames(proj_summary) %in% rownames(ctrl_samples)),]

# Print out proj_summary_ctrl
proj_summary_ctrl

  1. We would like to add in the batch information for the samples in proj_summary_ctrl. Find the rows that match in ctrl_samples.
# Match the rownames of proj_summary_ctrl to the rownames of ctrl_samples
m <- match(rownames(proj_summary_ctrl), rownames(ctrl_samples))

# Print match

### Reading in and inspecting data

1. Using the `animals.csv`, read the `.csv` file into your environment and assign it to a variable called `animals`. **Be sure to check that your row names are the different animals.**

```{r}

# Read in animals.csv
animals <- read.csv("data/animals.csv")

# Print animals
animals
```

2. Check to make sure that `animals` is a dataframe.

```{r}
#| label: class_animals
# Check the class of animals
class(animals)
```

3. How many rows are in the `animals` dataframe? How many columns?

```{r}
#| label: dim_animals
# Number of rows in animals
nrow(animals)

# Number of columns in animals
ncol(animals)
```

### Data wrangling

1. Extract the `speed` value of 40 km/h from the `animals` dataframe.

```{r}
#| label: extract_first_row_first_column
# Various methods to extract the speed value of 40 km/h
animals[1,1]
animals[which(animals$speed == 40), 1]
animals[which(animals$speed == 40), "speed"]
animals$speed[which(animals$speed == 40)]
```

2. Return the rows with animals that are the `color` Tan.

```{r}
#| label: rows_with_color_tan
# Two way to return the rows with the animal color as Tan
animals[c(2,5),]
```

3. Return the rows with animals that have `speed` greater than 50 km/h and output only the `color` column. Keep the output as a data frame.

### The `%in%` operator, reordering and matching

In your environment you should have a dataframe called `proj_summary` which contains quality metric information for an RNA-seq dataset. We have obtained batch information for the control samples in this dataset. **Copy and paste the code below to create a dataframe of control samples with the associated batch information**:

```{r}
#| label: create_ctrl_samples_df
# Read in proj_summary if needed
proj_summary <- read.table(file = "data/project-summary.txt", header = TRUE, row.names = 1)

# Create ctrl_samples dataframe
ctrl_samples <- data.frame(row.names = c("sample3", "sample10", "sample8", "sample4", "sample15"), 
                            date = c("01/13/2018", "03/15/2018", "01/13/2018", "09/20/2018","03/15/2018"))
```

1. How many of the `ctrl_samples` are also in the `proj_summary` dataframe? Use the %in% operator to compare sample names.

```{r}
#| label: shared_ctrl_samples_proj_summary
# Number of shared samples between ctrl_samples and proj_summary
length(which(rownames(ctrl_samples) %in% rownames(proj_summary)))
```

2. Keep only the rows in `proj_summary` which correspond to those in `ctrl_samples`. Do this with the %in% operator. Save it to a variable called `proj_summary_ctrl`.

```{r}
#| label: subset_proj_summary_by_ctrl_samples
# Subset proj_summary by the samples within ctrl_samples
proj_summary_ctrl <- proj_summary[which(rownames(proj_summary) %in% rownames(ctrl_samples)),]

# Print out proj_summary_ctrl
proj_summary_ctrl
```

3. We would like to add in the batch information for the samples in `proj_summary_ctrl`. Find the rows that match in `ctrl_samples`.

```{r}
#| label: match_rownames_between_proj_summary_ctrl_ctrl_samples
# Match the rownames of proj_summary_ctrl to the rownames of ctrl_samples
m <- match(rownames(proj_summary_ctrl), rownames(ctrl_samples))

# Print match
m
```

4. Use `cbind()` to add a column called `batch` to the `proj_summary_ctrl` dataframe. Assign this new dataframe back to `proj_summary_ctrl`.

```{r}
#| label: add_batch_information
# Using the match, add the batch information
proj_summary_ctrl <- cbind(proj_summary_ctrl, batch=ctrl_samples[m,])

# Print proj_summary_ctrl
proj_summary_ctrl
```
